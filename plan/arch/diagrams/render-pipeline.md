- **Documented extensions use their real upstream grammar.** ZenUML registers lazily once and validates through its
  exact core-generated grammar/runtime, not the plugin's no-op. Disposable module workers avoid its measured retained
  SDK Errors array; abort/disposal/timeout always terminate workers and revoke script URLs. Only ten successful sources
  are cached, not ASTs or rejected results. Its newly injected legacy viewer CSS is removed only on an exact pinned
  SHA-256 match; borrowed/same-sized host CSS and SVG-local style survive. No React viewer or DOM-global patch is
  needed.
- **Root SVG clipping follows the browser viewport.** Cleaned-up viewBox-free sibling probes retain meet letterboxes and
  CSS transforms after correcting root HTML-flow displacement. Intentionally clipped glyphs are rejected before native
  bounds diagnostics; upstream text and viewport dimensions are not rewritten to hide overflow.

- **Headless errors cross as diagnostics, not parser graphs.** An owned-page facade preserves bounded data-only
  name/message strings in fresh Errors without cyclic parse state, custom getters or coercion. Control escapes and
  explicit truncation make rejection visible; the next valid request still produces native cells.

- **Scalar widths come from the full pinned policy, not approximate blocks.** A compact assigned W/F projection and
  complete zero categories use the reviewed narrow profile with explicit RI/modifier tailoring. New wide symbols and
  supplementary scripts preserve complete followers; ambiguous/unassigned symbols stay narrow. Host-specific profiles,
  variation/font shaping and terminal capabilities remain unfinished.

- **Remote cell boundaries are explicit, not inferred from text.** Experimental generic codec v2 carries UTF-16 lengths
  including empty followers, with independent base/result integrity checks and bounded descriptor-only validation.
  Ready-handshake capability intersection selects v2; old peers use exact single-scalar v1 or reject required v2 before
  traffic. Frame flow owns immutable snapshots and bounded/coalesced queues. Raw ANSI/PTY and daemon protocols remain
  separate. Actual disposed Mermaid cells cross JSON full/delta before terminal and browser source/pixel oracles.

- **Grapheme boundaries share the pinned Unicode 17 profile.** Plain/styled text helpers, width/cropping and incremental
  nested terminal joins reuse the existing segmenter, with ASCII shortcuts only where boundaries are unambiguous. SGR
  inside a cluster retains the first scalar's cell style and updates following cells. Terminal width growth repairs
  followers/cursor/insert/REP/wrapping. A text-free boundary cursor and incremental width state preserve up to 65,536
  units per cell without growing-cluster rescans; shared extra-text accounting covers main/alternate/history, with
  visible whole-cluster refusal on exhaustion. Assigned zero-width categories use an offline-checked compact projection
  of the pinned width data, not a partial mark regex. Native wide-pair repair must inspect ASCII-base keycaps and later
  extending marks too. These limits do not bound all grid/style/decoder memory or establish full shaping, width policy
  or remote wire parity beyond the separately bounded negotiated cell codec.

- **The fork is at the sink, not in the components.** A widget that emits `\x1b[` directly has broken the property that
  makes the browser build and the headless tests possible.
- **ANSI is addressed cell transport, not plain concatenation.** Unicode cells are cursor-addressed on both sink paths;
  empty wide followers do not print or advance, and printable ASCII retains its compact spans. Cursor controls end
  leading-mark joins too. Raw text remains governed by its own Unicode boundaries. UTF-16 chunk decoding holds one high
  surrogate across writes/resize, with explicit EOF flushing; it is separate from grapheme-boundary state.
- **The test path is a first-class sink**, not a mock. What a test reads is what a terminal would have been sent, which
  is why a mounted test can catch a paint that never happened.
- **Pending updates survive dirty-region filtering.** A layout/visibility update can flag an object as moved without
  changing its rectangle. It still belongs in the required render set: a simultaneous resize may have cleared the whole
  frame while a disappearing object supplies a dirty region elsewhere. Skipping stationary rows in that case leaves
  clipped document panels blank. Canvas and mounted document tests assert actual cells across this sequence.
- **Capability detection lives below the sink.** Truecolor, mouse tracking modes and kitty graphics are negotiated with
  the terminal; components ask for a colour and get the best available representation.
- **Browser wide glyphs own atomic spans.** The browser retains staged source cells and repaints both columns whenever
  either half of an existing/new pair changes. Continuations are present cells with empty parsed text (TextObject may
  style them), not ordinary spaces or missing cells. A replaced owner clears its old tail; resize drops all span state.
  Glyphs/backgrounds/decorations cover both owned columns while oversized narrow-font advances remain clipped to one.
  Retained grids refuse nonfinite/over-2,000,000-cell allocation before mutating geometry. This does not repair the
  scalar-only version-1 remote limitations or prove exact CSS font geometry; negotiated v2 preserves explicit cells.

## Optional full Mermaid compilation

The browser DOM is a measuring/compiler capability, not the visible document host. Deno uses an isolated owned Chromium
context; native frames remain usable after that compiler is disposed. Core/document imports do not load this optional
engine or Playwright.

Rough hatch curves use bounded control-hull subdivision rather than uniform distance sampling. A detached owning-DOM
probe measures retained partial-curve lengths without mutating the source. Native centerline traversal keeps original
subpixel endpoints, exact cell-entry/exit intervals and measured tangent glyphs; snapping endpoints first shifted some
curves by a cell. This preserves the native safety limits and circuit composition, not pixel-exact SVG stroke outlines.
