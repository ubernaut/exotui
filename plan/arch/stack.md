**Deno** (TypeScript, ESM, `deno.jsonc` workspace). Chosen for a batteries-included toolchain — formatter, linter,
type-checker, test runner, permissions, and `deno compile` — with no build step and no `node_modules`. Permissions
matter here: exomux spawns PTYs and opens a loopback socket, and the runtime makes that explicit.

**Bun 1.4+** is an additional host. `package.json` mirrors the published entrypoints and pins optional dependencies;
`bun.lock` records their resolution. Terminal, filesystem, process and socket services pass through `runtimeHost`. Deno
uses its native APIs through that boundary; Bun uses its native process/server/terminal APIs and Node filesystem
compatibility. Browser imports leave the host undefined and preserve the existing browser presenters. Bun does not
provide Deno's permission sandbox; application-level permission checks remain separate from runtime access.

## Surfaces

The private headless Mermaid page installs an owned facade over the actual renderer. Engine failures carry bounded
data-only name/message copies in fresh Errors, not cyclic parse results, causes or custom getters/coercion. Branded

Direct browser errors are unchanged. Both complete hosts test every registered parser's malformed body/context and

with zero precedence, otherwise narrow ambiguous/private/unassigned policy. One private delta decoder/binary lookup

ANSI prefix compaction classifies complete color commands through the shared atomic SGR parser. Only pure color-only
prefixes can replace active colors without resetting; combined attributes, malformed colors or other controls require
the conservative reset path. This retains compact color runs without leaking typography into independent cells.

conflate GCB Extend/SpacingMark with display width. Unicode boundary and tailored width cursors retain no label text;
nested terminals preserve 65,536-unit clusters with a shared 8,388,608-unit extra-text budget above two units per
indexed cell, including both screens/history. Whole-cluster U+FFFD refusals are visible and inspected; host-configurable
lower limits reject invalid values before grid allocation. This is not a total grid/style/decoder/ font/shaping memory
or full terminal capability guarantee. Default browser core does not import the full width registry solely to obtain its
zero-width set.

Incremental terminal input holds at most one undecided UTF-16 high surrogate, separate from UTF-8 decoding and bounded
pending controls. Geometry changes retain partial scalars; explicit `flushInput()` resolves them at EOF and `clear()`
discards them. ANSI sinks keep Unicode cells distinct through absolute cursor addresses, skip empty wide followers
without advancing the cursor and retain compact printable-ASCII spans. Cursor controls end zero-prefix joins as well as
visible joins; SGR alone retains them. This fixes authored cell transport, not the inherently ambiguous raw
concatenation of separately authored text or real-terminal shaping/capability behavior. Intrinsic layout explicitly maps
authoring tabs to TextBox's one-space representation before shared width/wrapping measurement.

Experimental generic `./remote` cell codecs default locally to v2 explicit UTF-16 boundaries. Before network traffic,
the existing ready handshake must negotiate `cell-frame.boundaries-v2`; absent agreement chooses exact single-scalar v1
(compound/empty cells explicitly reject). Strict bounded plain-data validation, base/result checksums and immutable
owned flow snapshots preserve cells/opaque styles without guessing widths. Actual old/new checkout modules are exercised
in separate private TCP processes, both directions including reconnect/resync. Raw ANSI/PTY and live daemon protocol/
descriptor behavior are unchanged; this is not a full terminal width/shaping or Mermaid completion claim.

The optional beta document surface uses the real Markdown component and built-in flex engine. Its bounded circuit
flowchart presentation shares the circuit router/package glyphs and theme-semantic cells. Optional-only graphs retain
directed ranks; side rails align with their consumers and single-node core ranks share an axis. Horizontal graphs keep
unconnected services on separate centered rows. Captions may use nearby free rows but cannot erase other edges or
junctions. This remains separate from the full experimental compiler's native scene pipeline and is the tech-stack
preview's current renderer.

The shared web presenter owns retained TextObject rows for the whole desktop. Their computed rectangle reads the
platform size reactively so existing rows grow with browser width; a nonreactive peek freezes the old clip even when the
application supplies wider content and Canvas clears/redraws after resize. This ownership is separate from each document
surface's clipping/scrolling model.

The default desktop owns portable launcher filtering/links, per-window fullscreen policies and native overlay modals.
Hosts optionally report pixel width because a one-pixel breakpoint crossing can leave the cell grid unchanged. Hidden
floating restore rectangles must not be recovered against a phone viewport while a window is fullscreen. Client focus
runs before child actions; release-only document activation lets selection cancel links. Copy extracts cached per-window
cells before compositing/context menus, with browser clipboard writing isolated in a host adapter supporting HTTP.

Small is the opening-banner/generator default; Graffiti and Standard are bundled alternatives. The existing FIGlet
parser retains raw hardblanks/layout flags for controlled horizontal smushing without changing legacy kern stamps.
Browser Butterchurn defaults to bounded generator noise; microphone input is an explicit Settings action. The maximum
distortion alert uses the window host's modal overlay stack, shared cell geometry and frame clock, not a DOM dialog or
private timer. The old saved rate 0.2 migrates to 0.02 once; other rates and versioned choices are preserved.

## Storage and formats

- **Themes** — one JSON document per theme (`ThemeDocument` v2: name plus a sparse map of token to RGB), in
  `~/.config/exomux/themes/`. Written to a temporary file and renamed, so an interrupted save cannot leave half a theme.
- **exomux config** — `~/.config/exomux/exomux.json`, watched for live shader changes.
- **Session state** — `~/.local/state/deno-tui/exomux/`: one host descriptor per session plus a window layout. The
  descriptor carries the loopback URL, an auth token, and the capabilities the daemon advertises.
- **Protocol** — JSON over a loopback WebSocket, token-authenticated, with a bounded replay ring per session.
